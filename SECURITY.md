# Security policy

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository. If private reporting is unavailable, contact the repository owner through their GitHub profile and include only the information needed to reproduce the issue.

## Sensitive data

Never commit database URLs, Neon API keys, owner tokens, local `.env` files, signing credentials, or real user data. Rotate any secret that has been exposed and report the exposure privately.
